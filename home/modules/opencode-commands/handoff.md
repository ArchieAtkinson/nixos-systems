---
description: Write a handoff summary for a fresh session
---

Write a handoff summary of this session under these headings:

- **Objective** — what we set out to do.
- **Decisions** — what was settled, and why.
- **Completed** — what is done and how it was verified.
- **Next Move** — the single next step, with the command or file to start from.
- **Relevant files** — exact paths, plus any commits or branches.

Keep it under ~30 lines and cite real paths and commands. Do not start new
work or repeat the analysis here.
